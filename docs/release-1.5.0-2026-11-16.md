# Проверка выпуска MirrorPatch 1.5.0

Дата: 2026-11-16. Платформа: Windows x64. Native patch version 4.

## Состав и назначение

Исправления моделей и аудиомаршрутов закреплены в `39a7795`.
Релиз добавляет выбор опубликованных Flash Lite/image-experiences из серверной
конфигурации, строгую обработку неизвестных model ID и отдельные production
маршруты STT gRPC и RAP Voice/TTS. Списки моделей UI не расширяются.

Проверенные версии: CLI/Hub 1.5.9, IDE 2.7.0, Manager 2.32.1, конкретные
закреплённые хеши. Номер версии приложения без проверки хеша недостаточен.
Лицензии, entitlement, квоты и серверные решения не подменяются. Изменения
безопасности ограничены приложенными read-only исследованиями; отключение
проверок в выпуск не входит.

## Подтверждённые проверки перед выпуском

- **84 Python-теста:** native окна, выбор источника, сохранность backup,
  обновление прежних patch versions, статус, rollback и проверка упаковки.
- Runtime: `go test ./...` и `go vet ./...` прошли.
- `py_compile` сборочного и smoke-скриптов, `git diff --check` прошли.
- Кандидат EXE собран PyInstaller 6.22.3. Выполнен frozen smoke с Python/Go,
  исключёнными из PATH дочерних процессов: версия 1.5.0, help, JSON-диагностика,
  install → status → повторный install → restore для CLI, Hub, Manager и IDE.
  После restore исходный SHA-256 восстановлен. Неизвестная сборка отклонена
  без записи. Использованы временные копии; установленный код не менялся.
- Кандидат проверен на pristine Manager и сохранённом до AICode frontend IDE.
  Финальная сборка повторно проверяется также на Manager с прежним локальным
  gate и pristine frontend IDE.

При подготовке найдено накопление старых prebuilt launchers в сборочном кэше.
Сборочный скрипт теперь удаляет устаревшие EXE из этого каталога перед сборкой;
manifest перечисляет только четыре актуальных launcher текущего patch v4.

## Реальные вызовы и границы доказательств

Предыдущие SDK-прогоны Manager подтвердили текст, изображение, STT, Voice/TTS,
квоты и сохранённую авторизацию. Подробные результаты, native hashes и границы
Tab-маршрутов приведены в [отчёте patch v4](sdk-models-and-voice-patch-2026-11-15.md).
Исторические GUI-проверки ответа и квот — в
[отчёте GUI](gui-aicode-and-quota-patch-2026-11-15.md).

Обновлённые Python и Go SDK дополнительно подтвердили реальные ответы
`gemini-3.8-flash-low` на установленном patch v4. Их новые permission RPC
возвращают `unsupported / cloud_conversations_disabled` на проверенном аккаунте;
из этого не делается вывод о модерации или лицензии. Изменение разрешений
подтверждено только протокольным стендом.
[Проверка SDK](https://github.com/Lotargo/antigravity_engine_sdk/blob/main/docs/VALIDATION-SECURITY-2026-11-16.md).

Свежий OAuth, все модели и физический микрофон в рамках упаковки повторно
не проверялись. Сквозное аудио CLI/Hub, другие версии и ОС, enterprise/ADC/API-key
не квалифицированы. Tab 404 и CCPA 403 не объявляются устранёнными.

## Происхождение файлов релиза

Финальный EXE пересобирается из чистого release commit; `build-info.json`
содержит его SHA, runtime fingerprint и версии инструментов. Source ZIP
формируется `git archive` из того же commit. Windows ZIP содержит EXE,
документацию и лицензии; `SHA256SUMS.txt` связывает четыре основных assets.
Перед публикацией выполняются повторный frozen smoke и сверка архивов/хешей.

Google native EXE, пользовательские профили, токены, OAuth-коды и частные
журналы в пакеты не входят. Authenticode-подпись отсутствует.

Локальные ignored материалы: `test_cache/release-1.5.0-*` и `dist/release/`.
Результат кандидата: `release-1.5.0-smoke-candidate.json`; финальный smoke
сохраняется отдельно, чтобы не заменять первоначальные доказательства.
