# Проверка выпуска MirrorPatch 1.4.0

Дата: 2026-11-15. Платформа выпуска: Windows x64. Итог: кандидат EXE прошёл
проверки установки и восстановления; пакет публикуется из чистого release commit.

## Исходники и рабочие исправления

`7ee087f` фиксирует перенос AICode на установленные GUI-приложения, реальные
квоты и завершение дочернего backend. Предшествующий CLI этап — `72f9554`.
Оформление, самостоятельная упаковка и запуск нового профиля выделены отдельно.

Проверенное покрытие: CLI/Hub 1.5.9, IDE 2.7.0, Manager 2.32.1. Допуск аккаунта,
модель и квота по-прежнему предоставляются сервером. Enterprise/ADC/API-key,
другие версии и новые AICode-профили для других ОС не квалифицированы.

## Автоматические проверки

- **82 Python-теста:** диагностика, авторизация, запись/откат, обновление v1 → v2,
  выбор источника, проверка bundled launcher и отказ от повреждённых загрузок.
- **Go tests и `go vet`:** выбор серверного experience, сохранение entitlement,
  SSE, кэш конфигурации и Windows Job Object.
- **`node --check`:** полный изменённый frontend из исходной IDE 2.7.0.
- **`git diff --check`:** без ошибок пробелов.
- Баннер отрисован локально и визуально проверен; текст и элементы не обрезаны.

## Готовый EXE без инструментов разработки

Сборка: Python 3.12.5, Go 1.26.3, PyInstaller 6.22.3; Python-зависимости закреплены
в `source/requirements-build.txt`. EXE содержит четыре проверенных prebuilt
launcher и runtime manifest. Бинарники Google не включены.

`scripts/smoke_release.py` запускал кандидат EXE с Go и Python, исключёнными из
PATH дочерних процессов. Проверены:

| Операция | Результат |
|---|---|
| `--version`, `--help` | MirrorPatch 1.4.0, актуальные команды |
| `--check --json` | Валидный отчёт компонентов |
| CLI install → status → install → restore | Успех; восстановлен исходный SHA-256 |
| Hub install → status → install → restore | Успех; восстановлен исходный SHA-256 |
| Manager install → status → install → restore | Успех для исходной и ранее патченной сборки |
| IDE install → status → install → restore | Успех для исходного и ранее патченного frontend |
| Неизвестная сборка | Отказ; целевой файл не изменён |

Все изменения smoke-проверок выполнялись на временных копиях. Боевые приложения
не перепатчивались проверкой релизного EXE. Замена `--source` не требуется, когда
оригинал уже доступен локально. Проверка неверной сетевой загрузки выполнена с
mock HTTP-ответом: файл не попадает в кэш и не устанавливается.

## Реальная генерация и квоты

CLI/Hub и установленный Manager ранее дали реальные ответы через AICode.
Пользователь подтвердил ответ в IDE и видимые квоты в обоих GUI после перезапуска;
подробности — в [отчёте GUI](gui-aicode-and-quota-patch-2026-11-15.md).

Дополнительно перед выпуском проверена **исходная** native-сборка Manager,
без прежнего локального gate. Новый prebuilt launcher с её исправленным hash
вернул `signed_in` и HTTP 200 с ответом `RELEASE_MANAGER_OK`. Это подтверждает
пригодность варианта для исходной установленной сборки, а не только ранее
изменённого EXE. Проверка выполнялась через собственный RPC native-компонента;
отдельный свежий OAuth в UI этим запуском не выполнялся.

## Упаковка и публикация

Финальная сборка повторяется после коммита из чистого дерева. `build-info.json`
связывает EXE с точным source commit и версиями инструментов. Git source ZIP
формируется из этого же commit; Windows ZIP включает EXE, документацию и
лицензии. `SHA256SUMS.txt` содержит контрольные суммы готовых assets.

В репозиторий и пакеты не включаются `test_cache`, пользовательские профили,
OAuth-коды, токены, частные журналы или установленный код Google. Обязательные
уведомления исходной базы и лицензии зависимостей сохранены. Релиз не подписан
сертификатом Authenticode; контрольные суммы служат для проверки целостности.
