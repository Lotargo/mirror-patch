# Почему интерфейс показывает 100% при расходуемых лимитах

Дата: 2026-11-16.

Свежий `GET https://aicode.googleapis.com/v1alpha:fetchQuotaStatus` вернул HTTP 200
и два разных представления квот в одном ответе:

| Данные ответа | Gemini | Claude / GPT |
| --- | --- | --- |
| buckets[], по моделям | 46,83456% | 80,3001% |
| quotaSummary.groups[], общая сводка | 100% | 100% |

У модельных bucket время восстановления приходится на 2026-11-22, у общей сводки
на 2026-11-23. При повторных чтениях дата общей сводки сдвигается, тогда как дата
модельных bucket остаётся прежней. Это похоже на сводку-заглушку, но реализация
расчёта на стороне сервера неизвестна. Нельзя утверждать точную причину такого
серверного поведения.

Встроенный `quotaSummaryResponseFromQuotaStatus` использует общую quotaSummary.
Нативный RetrieveUserQuotaSummary поэтому возвращает 100%; quotaInfo в карточках
GetAvailableModels тоже показывал 1. Патч не подставлял эти проценты сам.

Один короткий SDK Complete запрос Claude Sonnet 4.6 вернул `LIMIT_OK` за 2487 мс.
Между чтениями до и после него модельные bucket Claude/GPT изменились с
0.803001 до 0.800517: минус 0,2484 процентного пункта. Gemini не изменился,
общая сводка осталась на 100%. Это подтверждает расходуемую квоту, а не безлимит.
Другие параллельные действия аккаунта не исключались, поэтому это не универсальная
стоимость одного запроса и не формула расчёта лимита.

В совместимый launcher добавлен опциональный metadata receipt для SDK:
capability `quota_status_file=1`, при включённом AGY_MODEL_CATALOG_FILE.
Он сохраняет только типизированные поля квот в соседний файл `.quota.json`.
Оригинальный ответ Google пересылается без изменения. Секреты, заголовки OAuth,
лицензии и проценты не подменяются. Нативные patch offsets не менялись.

Portable AGY Server читает модельные bucket отдельно от сводки и показывает их
в разделе «Лимиты», с reset_at, checked_at, трёхчасовым кэшем и ручным обновлением.
Нулевое значение остаётся нулём; отсутствие данных не считается 100%.
Наблюдавшиеся отказы движка по квоте хранятся отдельно и не переписывают проценты.

Установленные IDE и Antigravity 2.0 при этом не менялись: их сводка может остаться
на 100%. Новая возможность включена в runtime portable-сервера. Успешная новая
генерация изображений этой проверкой не подтверждалась; прежний 429 остаётся
отдельным историческим фактом.

[Санитизированный ответ сервера и native-сводка](evidence/quota-source-2026-11-16.json).
Скрипт чтения — в игнорируемом `test_cache/quota-verification-2026-11-16/verify.py`.
SDK-проверка до/после и UI-артефакты — `antigravity_engine_sdk/reports/quota-2026-11-16/`.

Проверки: Go tests и vet в SDK, Go tests runtime, 15 Python installer tests;
Playwright на mock и реальном backend, 760/1160/1440, ручное обновление,
сохранённый снимок после перезапуска без запуска native. Генерационных проверок
сделано ровно одна; остальные обращения были чтением метаданных.

## Обновление отображения 2026-11-16

Поверх сохранённой диагностики добавлено исправление для штатного native:
успешный fetchQuotaStatus в compatibility launcher пересчитывает только известные
weekly-группы из модельных bucket. Для gemini-weekly выбираются gemini-*, для
3p-weekly — claude-* и gpt-*. Показатель группы — минимум известных корректных
остатков; при равном минимуме берётся наиболее поздний валидный resetTime.
Это консервативная политика отображения, не новая формула расхода квот.
Нулевые значения сохраняются; неизвестные группы и поля не переписываются.
Исходные модельные bucket, OAuth и entitlement остаются прежними.

Metadata receipt сохраняет исходный ответ до коррекции, чтобы не потерять
первоначальное расхождение серверных данных. В SDK UI отдельно вычисляет ту же
консервативную группировку для компактных индикаторов на странице «Сервер».
Отдельная вкладка «Лимиты» удалена, подробности перенесены в подсказки.

Установлены обновлённые Manager и Hub launcher; проверки launcher/native/backup
успешны. На установленном Manager фактический RetrieveUserQuotaSummary с
forceRefresh=true и false вернул 0.4683456/0.800517 и восстановление 2026-11-22.
GetAvailableModels.quotaInfo сохраняет собственные 100% defaults и не используется
для этого отображения. Физический GUI Hub/IDE отдельно не автоматизировался.
Первый metadata-прогон Manager завершился transient provider_error; повторный
ограниченный прогон прошёл. Дополнительных генераций не выполнялось.
