# Динамический AICode-патч обычного agy

Дата: 2026-11-15. Статус: реализован, применён к CLI из PATH; реальная генерация
после завершения и повторного запуска подтверждена. Публикация не выполнялась.

## Цель и результат

Заменить пробную фиксированную подстановку Flash Low на выбор experience из
серверного `fetchConfig`, сохранить выбранную пользователем модель и проверить
обычный установленный CLI с основным профилем после перезапуска.

Ранее штатный AICode-путь успешно получал `free-tier` / `Antigravity Starter Quota`
через `fetchLicenses`, но `aicodeConverter.ToRequestPayload` подставлял отсутствующий
в конфигурации `chat-gemini-3.1-pro-low`. Это давало 404 при генерации. Старый CCPA
путь отдельно возвращал 403 #3501; исправление использует встроенный personal
AICode-путь с серверной лицензией. Проверки OAuth, лицензии и entitlement в новом
native-компоненте не изменяются. Связанные первичные наблюдения:
[рабочий бесплатный путь](aicode-free-access-working-path-2026-11-15.md).

Установленный обычный CLI обновлён с 1.4.5 до hash-pinned официальной 1.5.9 с
исправлением конвертера. Прежний EXE сохранён отдельно. Backend IDE в `.gemini/bin`
этим действием не заменялся.

## Реализация

Исходники:

- `source/patcher/agy/aicode.py`: проверка исходной сборки, четыре ограниченных
  изменения native EXE, сборка launcher, атомарная установка, статус и откат.
- `source/patcher/agy/aicode_runtime/main.go`: запуск штатного CLI, адаптер AICode,
  получение и кэширование `fetchConfig`, сопоставление моделей и SSE-передача.
- `source/main.py`: команды `--agy-aicode install|status|restore`.
- `source/patcher/agy/patcher.py`: распознавание совместимой установки и защита
  launcher от старого gate-патча; интерактивный откат также знает новый формат.

Native-патч передаёт исходный `GenerateContentRequest.Model` в
`aicode.experience`. Исходный request удерживается через существующее сканируемое
GC поле конвертера; старое содержимое этого поля не используется обоими методами
конвертации ответа. Сохранены stack frames, места вызовов, Go safepoints и
существующие write barriers. Новые native-вызовы и код вне известных функций
не добавляются. Потоковый и непотоковый конструкторы исправлены согласованно.

В адаптере выбираются experience, присутствующие одновременно в
`availableExperiences` и группах `agySurfaceConfig.agentExperiences` или
`tieredFlashExperiences`. Запись должна иметь реальный `model.name` или `modelId`;
заглушка с одним `displayName` исключается. Правила выбора:

1. Точное имя experience, включая вариант с префиксом `models/`.
2. Однозначное совпадение `modelId`, `model.name` или `displayName`.
3. Если native-модель по умолчанию устарела и `--model` не задан, первый
   действующий agent experience в серверном порядке.
4. Неоднозначный model ID или неизвестный явный `--model` дают ошибку.

Меняется только поле `aicode.experience`; остальные поля запроса, включая
entitlement и неизвестные будущие параметры, сохраняются. Каталог команды
`agy models` и интерфейс выбора моделей остаются штатными; серверная проверка
experience выполняется при генерации. Итоговое имя выводится в stderr.

Launcher устанавливает `USE_AICODE=true` и временный `AICODE_ENDPOINT_URL` только
в окружении дочернего CLI. Адаптер слушает `127.0.0.1` на случайном порту с
случайным префиксом, принимает только перечисленные AICode-методы, включая
`streamGenerateContent?alt=sse`, и пересылает их на фиксированный HTTPS-host Google.
Redirect не выполняется. Серверные ошибки лицензии проходят без изменения.
Нет записи OAuth-заголовков, промптов или тела ответов адаптером. Конфигурация
кэшируется на пять минут, отдельно по текущей авторизации, только в памяти.
Штатное хранение сессии и собственные журналы CLI сохраняются.

## Защита установки и откат

Поддерживается только pristine официальный Windows x64 CLI 1.5.9:

```
source SHA-256: 8803c289cac04d6e53f2211592d9981c2d5760bc0d9b4a7f222ef6ecc7abb38a
native SHA-256: f4aa5af8dec3ce520d801411f6a52e9f3dcfe9014d1285c98715519623cef7f9
```

Исходник также проверяется по SHA-512 официального manifest. До изменения каждого
окна сравниваются исходные байты. Размер EXE сохраняется. Проверяемые file offsets:
`0x2742f06`, `0x2742f1d`, `0x2743916`, `0x27835b6`.

Рядом с обычным EXE установлены native companion, manifest с хешами и
`agy.exe.before-aicode`. Последний содержит прежнюю установленную 1.4.5
(SHA-256 `08168b9f2a124944c78f50261d05a4fdbe372c6f2c1935b9e09c3ab004ab0238`).
Исторический `.agybak` не меняется. Повторная установка целого патча идемпотентна;
несовпадающий manifest, изменённые файлы или бесхозный backup блокируют замену.
При ошибке установки восстанавливается прежний EXE. Launcher проверяет native-хеш
до запуска. Обычная проверка патчера распознаёт новый формат и не накладывает
исторические gate-правки поверх launcher.

Команды установки, статуса и восстановления приведены в README. Go нужен только
при установке из исходников; установленный launcher не требует Go или Python
для обычного использования. Автообновление CLI отключено в дочернем процессе.
Перед ручным обновлением необходимо выполнить restore и заново проверить новую
версию: неизвестные бинарные сборки не патчатся автоматически.

## Проверка

Автоматические проверки:

- Python: 69 тестов, включая 63 ранее существовавших; новый набор проверяет
  hash-pinning, точные границы native-изменений, повторную установку, исторический
  backup, откат, повреждённый companion и сбой атомарной установки.
- Go: выбор из меняющейся серверной конфигурации, неоднозначные aliases,
  исключение скрытых/отключённых записей, сохранение entitlement и неизвестных
  полей, SSE и query `alt=sse`, ограничения маршрутов, неизменённый 403 лицензии,
  разделение кэша между сессиями и обработка окружения.
- `go vet ./...` и `git diff --check`.

Реальные запросы, без debugger и без повторного браузерного входа:

| Проверка | Профиль | Выбор | Результат |
|---|---|---|---|
| Отдельная установленная копия | Изолированный, общий штатный keyring | `--model gemini-3.8-flash-medium` | `DYNAMIC_MEDIUM_OK`, SUCCESS, exit 0 |
| Обычный `agy` из PATH | Основной, без `--gemini_dir` | `--model gemini-3.8-flash-medium` | `AGY_INSTALLED_OK`, SUCCESS, exit 0 |
| Новый процесс после завершения предыдущего | Основной, без `--gemini_dir` | Без `--model`, выбран `gemini-3.8-flash-medium` | `AGY_RESTART_OK`, SUCCESS, exit 0 |

В последнем запросе зарегистрированы 26106 входных, 59 выходных и 52 thinking
токена; ответ получен за 13.84 с. Это реальный ответ модели, а не только успешный
вход или локальный статус патча. Штатная сохранённая авторизация пережила
завершение и повторный запуск процессов. Проверка не означает перезагрузку ОС.

Артефакты проверки в игнорируемом каталоге
`test_cache/aicode-dynamic-patch-2026-11-15/`:
`candidate-verification.json`, `installed-verification.json`, manifest отдельной
копии. Они содержат только результаты коротких проверочных промптов и имена
моделей; OAuth-токены в доказательства не выгружались.

## Ограничения и открытые вопросы

Работоспособность подтверждена для текущего аккаунта с бесплатным серверным
допуском, текущей конфигурации и Gemini Flash Medium. Остальные experience
сопоставляются динамически, но реальная генерация на каждом из них не проверялась.
Непотоковый конструктор исправлен и аудирован; живая проверка CLI использует SSE.
Отдельная длительная GC-нагрузка не выполнялась. Время жизни локального адаптера
связано с CLI; режимы с отделяющимся фоновым backend не покрываются. Pro/Ultra,
IDE/Hub, другие ОС и другие версии CLI не входят в подтверждённое покрытие. Штатный upstream source
Go недоступен; изменения нативного конвертера требуют повторного аудита при
обновлении. Доступность AICode и лимиты остаются под контролем сервера.
