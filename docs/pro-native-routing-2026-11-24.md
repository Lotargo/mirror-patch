# Google AI Pro: штатный маршрут и раздельные квоты

Дата проверки: 2026-11-24.

## Что происходило

AICode-launcher принудительно задаёт `USE_AICODE=true`. Это поддерживает
бесплатный personal-доступ через `aicode.googleapis.com`, но не является
универсальным маршрутом всех моделей платного аккаунта.

В проверенном Pro-аккаунте штатный Cloud Code PA вернул ответы Hydrogen,
Neon и Argon. Передача точного Hydrogen ID через AICode получила серверный 404.
Перечень AICode `fetchConfig` также не содержал семейство Gemini 4. Поэтому
подстановка другой модели или ослабление локальной проверки каталога проблему
не исправляют. Для этого аккаунта восстановлен нативный маршрут.

После восстановления установленного Manager проверены реальные ответы
`gemini-4-hydrogen-xhigh` и `gemini-4-carbon-medium` с исходными native model IDs.
Работа установленных приложений также подтверждена пользователем.

Это наблюдения для проверенного аккаунта и сборок, а не обещание доступа к любой
модели. Подписку, доступность и лимиты по-прежнему определяет сервер Google.

## Восстановление

Сохраните работу и закройте приложение. Для Manager:

```powershell
$manager = Join-Path $env:LOCALAPPDATA 'Programs/antigravity/resources/bin/language_server.exe'
.\MirrorPatch-windows-x64.exe --agy-aicode restore --profile manager --target "$manager"
```

Для backend IDE:

```powershell
$hub = Join-Path $env:USERPROFILE '.gemini/bin/agy.exe'
.\MirrorPatch-windows-x64.exe --agy-aicode restore --profile hub --target "$hub"
```

Восстанавливается сохранённый native EXE. Если лечение ранее сохранило
официальное автообновление Hub, используются соответствующие `before-heal`
EXE и updater-sidecar. Проверяются версия, официальный источник, размер и
SHA-512. Повреждённая либо отсутствующая recovery-пара блокирует восстановление.
При невозможности записать sidecar launcher возвращается в прежнее состояние.

Откат native-профиля не меняет OAuth и не выдаёт права аккаунту. Frontend IDE
проверяется отдельно; полный откат frontend выполняется профилем `ide`.

## Автоматическая проверка

Рядом с восстановленным EXE сохраняется `*.official-routing.json`, содержащий
выбор маршрута, профиль и SHA-256 файла. Учётных данных в нём нет.

- Подтверждённый native-файл отображается как штатный, не требующий launcher.
- Автоматическое лечение, включая принудительную перепроверку, не возвращает
  AICode на этот файл.
- Если EXE или маркер изменились, нужна повторная проверка; автоматическая
  установка совместимости остаётся запрещённой.
- Явная команда `--agy-aicode install` выбирает AICode снова и удаляет маркер
  только после успешной установки.

Маркер описывает целостность и выбранный режим. Успешный вход и генерация
подтверждаются отдельно.

## Недельный и пятичасовой лимиты

Платный тариф публикует оба окна одновременно. Уменьшение недельного лимита
само по себе не означает триал. В проверенном ответе сервера были отдельные
счётчики `gemini-weekly` и `gemini-5h` с различными остатками и датами сброса.

Прежняя коррекция брала минимум per-model счётчиков и записывала его в weekly
summary. Для Pro это смешивало разные окна. Теперь группы с несколькими окнами
передаются без такого изменения: серверные проценты и reset times сохраняются.
Историческая коррекция остаётся только для единственного legacy weekly bucket.

Проверки: Python-тесты, Go-тесты, `go vet` и frozen EXE install/status/restore
на изолированных копиях. Пользовательские профили, логи и файлы Google
не включаются в релиз.
