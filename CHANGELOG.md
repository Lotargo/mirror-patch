# Изменения

## 1.4.0 — 2026-11-15

- Personal AICode для обычного CLI, Hub IDE и Manager: вход, генерация и квоты.
- Выбор experience из серверного `fetchConfig`, без фиксированной модели.
- Исправление входа IDE 2.7.0 через фактический `fetchLicenses`.
- Штатный `FetchQuotaStatusFromAICode` для загрузки остатков и дат сброса квот.
- Windows Job Object устраняет оставшийся backend после закрытия launcher.
- Проверяемые хеши, отдельные профили, сохранение первого backup и откат обновления.
- Новый пункт меню 13, готовые launchers внутри Windows EXE и проверенное получение
  официального исходного CLI при необходимости. Python/Go нужны только разработчику.
- Достоверные статусы компонентов и отдельная диагностика авторизации Hub.
- README и About в оформлении MirrorPatch, ссылки на текущий репозиторий,
  собственные реквизиты поддержки и сохранённое указание исходной базы.

Живые проверки выполнены для Windows x64: CLI/Hub 1.5.9, IDE 2.7.0,
Manager 2.32.1. Версия не обещает совместимость с неизвестными сборками или
неограниченные квоты.
