# Изменения

## 1.6.0 — 2026-11-24

- Откат AICode-совместимости выбирает штатную маршрутизацию. Проверенный маркер
  не позволяет автоматическому лечению вернуть принудительный AICode-маршрут.
  Явная повторная установка совместимости переключает режим обратно.
- Восстановление Hub после автообновления использует сохранённую официальную
  сборку с проверкой пары EXE/sidecar, версии, размера и SHA-512. При ошибке записи
  выполняется откат; неподтверждённый файл не восстанавливается.
- Подтверждённое автообновление Hub, перезаписавшее launcher, можно излечить
  с сохранением recovery-копий и синхронизацией updater-sidecar.
- Раздельные недельные и пятичасовые окна Pro сохраняют серверные значения:
  минимум другого модельного счётчика больше не подставляется в недельный лимит.
- Desktop Helper для проверки и лечения установленных модулей; файловая
  целостность и доступ аккаунта проверяются отдельно.

- Метаданные полного каталога `availableExperiences` для SDK: модели вне agent
  picker и опубликованные уровни мышления сохраняются в приватной папке процесса.
  Это позволяет восстановить Flash Lite aliases и обновлять список по подписке
  без дополнительного фонового опроса. Авторизация и prompts в receipt не попадают.

- Опциональные Google safety settings для серверного launcher: четыре категории,
  перечитывание JSON перед запросом, сохранение исходных defaults и receipt
  отправленного массива. SDK-сервер управляет настройками через свой API;
  другие модели, agent monitors и разрешения инструментов сохраняются.

## 1.5.0 — 2026-11-16 — native patch v4

- Прямой выбор включённых experiences из `fetchConfig`, включая Flash Lite и генерацию изображений, без расширения UI.
- Отдельные production-маршруты STT gRPC и RAP Voice/TTS вместо локального HTTP-адаптера.
- Неизвестный RPC model ID отклоняется без подстановки другой модели; для непубликуемых Tab IDs указывается причина.
- Обновление patch v2/v3 с сохранением исходного backup и rollback; новые pinned native hashes.
- Реальные SDK-проверки текста, JPEG, STT, голосового аудио, квот и сохранённой авторизации. Причина Tab 404/CCPA 403 #3501 разобрана отдельно.

## 1.4.0 — 2026-11-15

- Personal AICode для обычного CLI, Hub IDE и Manager: вход, генерация и квоты.
- Выбор experience из серверного `fetchConfig`, без фиксированной модели.
- Исправление входа IDE 2.7.0 через фактический `fetchLicenses`.
- Штатный `FetchQuotaStatusFromAICode` для загрузки остатков и дат сброса квот.
- Windows Job Object устраняет оставшийся backend после закрытия launcher.
- Проверяемые хеши, отдельные профили, сохранение первого backup и откат обновления.
- Новый пункт меню 13, готовые launchers внутри Windows EXE и проверенное получение
  официального исходного CLI при необходимости. Python/Go нужны только разработчику.
- Достоверные статусы компонентов и отдельная диагностика авторизации Hub.
- README и About в оформлении MirrorPatch, ссылки на текущий репозиторий,
  собственные реквизиты поддержки и сохранённое указание исходной базы.

Живые проверки выполнены для Windows x64: CLI/Hub 1.5.9, IDE 2.7.0,
Manager 2.32.1. Версия не обещает совместимость с неизвестными сборками или
неограниченные квоты.
