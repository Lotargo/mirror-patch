# MirrorPatch 1.5.0 — Flash Lite, изображения и Voice

Native patch v4 расширяет прямой SDK/RPC-доступ и исправляет аудиомаршрутизацию
на проверенных Windows-сборках. Выбор моделей в интерфейсе не расширяется.

- Выбор всех включённых experiences с реальной моделью из серверного
  `fetchConfig`, включая Flash Lite и image-experiences. Порядок серверного
  agent-каталога сохраняется для выбора по умолчанию.
- Неизвестный model ID отклоняется без незаметной замены. Непубликуемые `tab_*`
  получают отдельное объяснение ограничения AICode-маршрута.
- STT gRPC и RAP Voice/TTS используют собственные production endpoints.
  Это устраняет отправку TLS-аудиосоединения в локальный plaintext HTTP-адаптер,
  вызывавшую `Couldn't connect`.
- Обновление установок patch v1/v2/v3/v4 сохраняет исходный backup и откат;
  native проверяется по закреплённым хешам.

## Скачать

- **MirrorPatch-windows-x64.exe** — готовый патчер, Python и Go не нужны.
- **MirrorPatch-windows-x64.zip** — патчер, документация и лицензии.
- **MirrorPatch-v1.5.0-source.zip** — исходники точного release commit.
- **build-info.json** и **SHA256SUMS.txt** — происхождение сборки и SHA-256 assets.

Закройте IDE и Antigravity 2.0 перед установкой. В патчере используйте
**13 — AICode access + quotas**, затем выберите нужные установки. После обновления
проверьте ответ модели и Models & Usage. Для отката используйте restore того же
профиля; для IDE восстанавливаются `ide` и `hub`.

## Проверенное покрытие и границы

CLI/Hub 1.5.9, IDE 2.7.0 и Manager 2.32.1, Windows x64, конкретные закреплённые
хеши. Реальные model/image/STT/Voice проверки выполнены через SDK Manager;
авторизация, квоты и известные GUI-исправления сохранены. Исследования Tab и
runtime-мониторов приложены как отчёты; отключение мониторов в выпуск не входит.

Сервер по-прежнему определяет доступ, entitlement и квоты. Наличие записи в
каталоге не гарантирует успешный вызов. Tab 404 и CCPA 403 не объявляются
исправленными. Enterprise/ADC/API-key, другие версии и новые профили на
Linux/macOS не квалифицированы. Изолированное озвучивание произвольного текста
не заявляется: проверялось аудио ответа Voice.

Готовый EXE проверяется установкой, повторной установкой, status и restore на
временных копиях без Go/Python в PATH. Пакеты формируются из чистого commit.
Google native EXE, профили, токены и частные журналы в assets не включаются.
Authenticode-подписи нет; для проверки целостности приложен SHA-256.
