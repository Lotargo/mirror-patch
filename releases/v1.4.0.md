# MirrorPatch 1.4.0 — AICode, модели и квоты

Восстанавливает personal AICode-путь для Antigravity CLI, IDE и Manager:
вход, реальные ответы моделей и отображение квот после перезапуска.

## Что изменилось

- IDE получает фактическую лицензию через `fetchLicenses`, а native backend
  отправляет генерацию с experience из актуального `fetchConfig`.
- Квоты загружаются штатным `FetchQuotaStatusFromAICode`; серверные остатки и
  сроки сброса не подменяются.
- Windows Job Object устраняет оставшиеся процессы native backend после закрытия.
- Отдельные профили, проверка хешей, резервные копии и обратимое обновление v1 → v2.
- Пункт меню **13 — AICode access + quotas**. Готовый EXE содержит launchers:
  установленный Python или Go не требуется.
- Новое оформление README и About, собственные ссылки и поддержка проекта.
- Поддержка исходного frontend IDE 2.7.0 и известного состояния старого локального
  патча; для personal-входа не требуется повторная регистрация через `onboardUser`.

## Скачать и запустить

Скачайте `MirrorPatch-windows-x64.exe` или ZIP с документацией. Сохраните работу,
закройте приложения Antigravity и выберите пункт **13**. После установки откройте
их снова и проверьте короткий ответ модели и **Settings → Models & Usage**.

Если исходного CLI нет локально, патчер скачает проверенную официальную 1.5.9
с сервера Google, около 232 МБ. Исходный Manager берётся из установленной сборки
или предоставляется через `--source`. Бинарники Google в assets не входят.

## Совместимость

- Windows x64, обычный CLI и Hub **1.5.9**;
- Antigravity IDE **2.7.0**;
- Antigravity 2.0 / Manager **2.32.1**;
- проверенные хеши и personal Google-аккаунты.

Неизвестные сборки отклоняются. Доступность моделей, лицензия и лимиты остаются
под контролем Google. Enterprise/ADC/API-key и другие ОС новым AICode-профилем
не квалифицированы. Старые пункты меню сохранены отдельно.

[Руководство](https://github.com/Lotargo/mirror-patch/blob/v1.4.0/docs/manual.md)
содержит команды проверки и восстановления. Перед ручным обновлением native
выполните откат; после обновления самого GUI перепроверьте статус патча.

## Проверка выпуска

82 Python-теста, Go-тесты и `go vet` пройдены. Готовый EXE проверен на отдельных
копиях: установка, статус, повторное применение и откат профилей cli/hub/manager/ide
с Go и Python, исключёнными из PATH.

Живые ответы CLI, Hub и Manager проверены; пользователь подтвердил генерацию
в IDE и квоты в обоих интерфейсах после перезапуска. Автоматические проверки и
smoke готового EXE описаны в [отчёте выпуска](https://github.com/Lotargo/mirror-patch/blob/v1.4.0/docs/release-1.4.0-2026-11-15.md). SHA-256 пакетов — в `SHA256SUMS.txt`.
