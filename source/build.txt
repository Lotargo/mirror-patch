Run from the repository root on Windows x64:

python -m venv .venv
.venv\Scripts\python.exe -m pip install -r source/requirements-build.txt
.venv\Scripts\python.exe scripts/build_windows.py

The working tree must be committed before source ZIP packaging.
Use --build-only for a candidate, --package-only for an already verified clean build.
See releases/README.md for checks, assets, licenses and publication.

The new AICode release profiles are audited for Windows x64 only.
Legacy Linux/macOS source paths remain in the repository but are not release-qualified.
